# 产品全量功能清单

> 最后核对：2026-10-13
>
> 本文是 FlowChat 唯一的产品范围、稳定 ID 和状态来源。其他文档只引用 ID，不复制状态。

## 1. 状态定义

| 状态 | 含义 |
|---|---|
| 已实现 | 代码中存在，且能在本地或线上稳定复现 |
| 部分实现 | 主路径可用，但存在已知边界或未收口项 |
| 待收口 | 代码存在但行为未达产品预期，或缺少验证证据 |
| 已暂缓 | 已确认要做但当前不做，见对应 roadmap |
| 不在范围 | 明确不作为本项目能力 |
