# 生产故障经验

> 最后核对：2026-10-13
>
> 本文只保留可复用的经验，统一使用「现象 → 根因 → 预防门禁」三段式。完整现象清单见[常见错误与排错记录](../../troubleshooting.md)，部署过程见[Vercel 部署全记录](../../deployment-vercel.md)。

## 1. 环境变量已配置但线上仍读不到

- **现象**：页面能打开，一发送消息就 500，Runtime Logs 报缺少某个服务端变量。
- **根因**：变量作用域只勾了 Preview，未勾 Production；或修改变量后没有重新部署。
- **预防门禁**：改环境变量后固定执行「保存 → 在 Deployments 页面 Redeploy → 复测一次发消息」；把作用域勾选写进部署检查清单。

## 2. Vercel 连不上国内 AI 端点

- **现象**：本地调用上游正常，部署后请求超时或直接失败。
- **根因**：Vercel 函数运行在海外区域，到 `api.siliconflow.cn` 的网络路径不可靠。
- **预防门禁**：优先使用国际节点 `https://api.siliconflow.com`；把供应商切换保持为「只改环境变量」的低成本操作，必要时准备兼容 OpenAI 协议的备选供应商。

## 3. 流式变成「一次性蹦出」或中途断开

- **现象**：AI 回复不是逐字显示，而是长时间空白后一次出现；或流在中间突然结束。
- **根因**：边缘代理缓冲了 SSE；或缺少 `Content-Type: text/event-stream`；或函数执行时长触达上限；或前端误用 `response.json()`。
- **预防门禁**：SSE 响应头必须同时具备 `text/event-stream`、`Cache-Control: no-cache, no-transform`、`X-Accel-Buffering: no`、`Content-Encoding: identity`；路由导出 `maxDuration`；前端只能用 `body.getReader()` 逐块读取。

## 4. 中文乱码与末尾丢字

- **现象**：回复里出现 `nâ`、`��` 等乱码；或最后几个字没显示出来。
- **根因**：TCP 分包切断 UTF-8 多字节字符（中文占 3 字节）；或流结束时缓冲区未刷出。
- **预防门禁**：解析按行进行且跨 chunk 保留不完整行（`lineBuffer` / `StreamProcessor.buffer`）；每次流终止路径都必须先 `flush()` 再收尾。

## 5. 数据库连接超时与权限拒绝

- **现象**：本地正常，线上偶发连接超时；或写入报 `42501 Permission denied`。
- **根因**：Serverless 每次请求可能新建连接，耗尽连接数；或误用了受 RLS 限制的 anon key。
- **预防门禁**：连接使用 Connection Pooling（端口 6543）；服务端一律使用 service role key；确保 `lib/supabase.ts` 不被客户端组件导入。

## 6. 鉴权 401（本地正常、线上失败）

- **现象**：线上登录后调用接口仍返回 401。
- **根因**：前端 publishable key 与后端 secret key 来自不同 Clerk 环境（一个 Production、一个 Development）；或回调域名未加入白名单。
- **预防门禁**：把「前后端 Key 同环境 + 域名白名单」作为上线前的固定检查项。

## 7. 本地正常、构建失败

- **现象**：`npm run dev` 无异常，`npm run build` 报 TypeScript 错误。
- **根因**：`dev` 不做完整的类型检查与产物构建。
- **预防门禁**：推送前必须本地执行 `npm run build`；后续应在 CI 中前置该步骤（见[测试与持续集成路线](../../roadmap/测试与持续集成路线.md)）。

## 8. 排查方法论（保留的通用路径）

1. **先分层**：用浏览器 Network 面板区分「前端问题」与「后端问题」。401 查鉴权与变量、500 查 Runtime Logs、`fetch failed` 查网络与上游连通性。
2. **逐层验证上游调用**：网络连通 → 鉴权格式（前缀与空格） → Key 有效性（余额与端点） → 请求体格式 → 响应结构。
3. **最小复现**：剥离业务逻辑，用最小请求直接打上游。能通则问题在业务代码，不通则在配置或网络。
4. **日志即证据**：在关键节点保留完整响应文本；本项目在开发环境打印上游错误前 200 字符，生产环境隐藏以避免泄漏。
