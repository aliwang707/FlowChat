### 1.2 未覆盖（未被任何自动化证明的行为）

| 行为 | 风险 |
|---|---|
| 限流 429 分支 | 限流参数被误改不会被发现 |
| 末条消息角色校验 | 防伪造请求的校验失去保护 |
| 上游 4xx/5xx / 无 body 的 502 分支 | 错误映射回归无人可测 |
| 会话归属校验（403 / 404） | 越权防护是本项目最重要的安全边界，却无自动化 |
| 删除会话的消息级联清理 | 可能留下孤儿数据 |
| SSE 跨 chunk 拼行与中文截断 | 最容易复发的一类问题 |
| 首 token 直出与节流合并 | 渲染体验回归无感知 |
| 取消 / 超时 / 超长的收尾与落库幂等 | 数据一致性无保护 |
| 会话切换竞态拦截 | 竞态回归无感知 |
| 组件渲染与无障碍属性 | 无保护 |

## 2. 人工验证基线

以下项目当前只能人工验证，每次改动相关代码后必须重跑（完整清单见[Vercel 部署全记录](../deployment-vercel.md)第 4 节）：

- [ ] 未登录访问受保护接口返回 401
- [ ] 登录后能收到逐字流式回复，而非一次性返回
- [ ] 新建会话后刷新页面，历史消息不丢
- [ ] 取消生成后：短内容气泡被移除、长内容保留并带 `[已取消生成]`、数据库中有且仅有一条 assistant 消息
- [ ] 快速连续切换会话，消息不串台
- [ ] 深色模式跟随系统；手动切换后页面与代码块主题一致（当前此条不通过）
- [ ] 移动端窄屏侧边栏抽屉与遮罩可正常开合
- [ ] 断网或上游故障时展示友好错误提示，不白屏、不卡死
